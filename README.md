# Youness Naim — Portfolio

Portfolio professionnel de Youness Naim, développeur Full Stack spécialisé dans le développement d'applications web modernes.

## Technologies

- **Frontend** : React.js, JavaScript, Vite, Tailwind CSS, HTML, CSS
- **Backend** : Node.js, Express.js, Laravel, PHP
- **Base de données** : MySQL, MongoDB, Sequelize
- **Outils** : Git, GitHub, VS Code

## Fonctionnalités

- Design responsive (mobile, tablette, desktop)
- Section À propos, Compétences, Projets, Expérience, Formation et Contact
- Téléchargement du CV
- Navigation fluide avec ancres
- Interface sombre moderne et professionnelle

## Structure du projet

```
src/
├── components/  # Composants réutilisables (Navbar, Footer)
├── sections/    # Sections du portfolio (Hero, About, Skills, Projects, Experience, Education, Contact)
└── data/        # Données structurées (projects, skills, experience, education)
```

## Installation

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Aperçu

Pour visualiser la version de production, utilisez :

```bash
npm run preview
```
